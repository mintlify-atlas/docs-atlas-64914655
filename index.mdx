## Get Started

<Steps>
  <Step title="Configure your environment">
    Copy `.env.example` and set your `SECRET_KEY`, SQL Server connection details, and PostgreSQL credentials. See [Environment Variables](/configuration/environment).
  </Step>
  <Step title="Start the server">
    Install dependencies with `pip install -r requirements.txt` and launch the app with `uvicorn backend.main:app --reload`. The application serves both the API and frontend from a single process.
  </Step>
  <Step title="Log in">
    Open your browser at `http://localhost:8000`. Enter your username and password — a JWT token is issued and stored in an HttpOnly cookie for your session.
  </Step>
  <Step title="Search for a customer">
    Type a numeric customer code in the search bar at the top of the dashboard and press Enter. All modules load the customer's data immediately.
  </Step>
</Steps>

<Note>
  CNEL Analytics requires access to two databases: the CNEL EP SQL Server instance (read-only, historical data) and a local PostgreSQL database (users, roles, and access logs). Both must be reachable before starting the server.
</Note>
